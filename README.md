## Setup

1. Clone the repository
2. Create a virtual environment
3. Install dependencies:

```bash
pip install -r requirements.txt
```

## Requirements

The project uses Python libraries commonly used in machine learning and data science, including:
- numpy
- pandas
- scikit-learn
- matplotlib
- seaborn
- jupyter
